## 3. AI推荐算法优化

### 3.1 当前问题

**UserCF算法局限：**
- 冷启动问题：新用户没有历史数据
- 稀疏性问题：投递记录稀疏时效果差
- 缺乏多样性：总是推荐相似职位

### 3.2 优化方案

**混合推荐策略：**
1. **基于内容的推荐** (Content-Based)
   - 提取简历关键词（技能、学历、期望薪资）
   - 匹配职位描述相似度
   - 解决冷启动问题

2. **协同过滤增强** (UserCF + ItemCF)
   - UserCF：相似用户的投递记录
   - ItemCF：相似职位的投递记录
   - 混合权重：70% UserCF + 30% ItemCF

3. **热度加权**
   - 热门职位给予适度曝光
   - 防止马太效应过度

### 3.3 实现步骤

1. **职位向量化**
   - 提取职位描述的TF-IDF特征
   - 存储在position表的feature字段（JSON）

2. **简历向量化**
   - 提取简历的技能、经历关键词
   - 实时计算或缓存

3. **混合推荐API**
   ```java
   // 新的推荐接口
   GET /position/recommendV2?userId=123&strategy=hybrid
   
   // 返回混合推荐结果
   {
     "userCF": [...],
     "itemCF": [...],
     "contentBased": [...],
     "final": [...]  // 混合后的结果
   }
   ```
